# 📚 Book Recommendation Chatbot using IBM Watson Assistant

This project is a **chatbot** that recommends books based on user preferences.  
It is built using **IBM Watson Assistant**.  

👉 [Click here to try the chatbot](https://web-chat.global.assistant.watson.appdomain.cloud/preview.html?backgroundImageURL=https%3A%2F%2Fau-syd.assistant.watson.cloud.ibm.com%2Fpublic%2Fimages%2Fupx-a5c67ae7-be54-4509-9356-ab26d262d848%3A%3Ae8c6c835-8e50-4dbe-9090-f4ac319bf6f0&integrationID=1e945c05-7190-4784-88f9-952ef0892591&region=au-syd&serviceInstanceID=a5c67ae7-be54-4509-9356-ab26d262d848)

---

## ✨ Features
- Recommends books by genre  
- Provides multiple options to explore  
- Built with **intents, entities, and dialog** in Watson Assistant  

---

## 🚀 How to Use
1. Click the link above.  
2. Start chatting with the bot.  
3. Select a book genre and get recommendations.
